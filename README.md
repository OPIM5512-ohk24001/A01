# A01 — California Housing Dataset Boxplot

## Purpose
Generate a boxplot visualization of the California Housing dataset to explore feature distributions.

## Data
This project uses the **California Housing dataset** from scikit-learn, which contains 20,640 samples with 8 features about California housing prices from the 1990 census.

## How to Run
```bash
# Install dependencies
pip install -r requirements.txt

# Run the script
python src/boxplot.py
```

## Expected Output
A saved boxplot image at `figs/boxplot.png` showing standardized feature distributions.
```
